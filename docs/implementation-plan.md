# 实施约定

Java 17 独立 Maven 库。原项目 D:/Development/RuoYi-Vue 只读参考，不修改。只提供连接、协议分类和订阅转发，不迁移金库、主房间、数据库、Redis、潘多拉关联、连击计算或自动账号登录。

1. 协议测试：小端包头、拆包粘包、长度验证、UTF-8、STT 转义、嵌套字段。
2. 分类：聊天、dgb、钻粉开通/续费、爵位、潘多拉广播、voiceDanmu、rss、通用消息；保留原文及未知字段。
3. 订阅：同房间跨类型串行，全局/房间筛选/多类型/类型化订阅；订阅独立于连接，取消等待已运行回调完成。
4. 连接：connect/disconnect；主动断开不重连，异常断线退避重试；旧连接代次隔离，连接超时，心跳和静默检测。
5. 发送：独立连接，外部不可变凭据，更新只重建发送通道，支持按通道重连；有界队列、单个在途请求，超时结果未知并替换连接，禁止自动重发。
6. 验证：离线协议和生命周期测试、本地 WebSocket 模拟服务器集成测试、示例和 README。真实账号发送不作为自动测试。

同一房间接收顺序不等于服务端业务发生顺序；断线不补历史，也不承诺去重。disconnect 完成前排空已接纳的消息；回调不得阻塞等待自身所在房间的生命周期操作。所有公开凭据输出必须脱敏。
